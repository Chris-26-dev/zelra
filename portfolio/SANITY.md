## Title
Zelra: Real-time Team Chat

## Description
Zelra is a real-time team chat app for people who work across several workspaces. It has channels, direct messages, threaded replies, emoji reactions and image sharing, and every update reaches all members instantly. I built it with Next.js 15, React 19 and Convex, which handles the database, server functions and live subscriptions. Sign-in works with email and password, Google or GitHub.

Some features beyond the basics:
- **Multi-workspace rail**: switch workspaces in one click, join with an invite link plus a 6-character code, and manage roles (admin or member).
- **Command palette (Ctrl+K)**: jump to any channel, person, workspace or action.
- **Rich text editor** built on Quill, with formatting, emoji, image attachments and per-channel drafts.
- **Day and night themes** and a responsive layout with dedicated mobile navigation.
- **Server-side authorization** on every Convex query and mutation, plus a Vitest + convex-test regression suite that runs in GitHub Actions CI.
